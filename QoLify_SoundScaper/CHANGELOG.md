# Changelog

## 1.2.0
- Each section now also stores the sound channel count (the game's "Sound Channels"
  setting, how many sounds play at once). It gets its own row in the window and is
  applied and synced exactly like the volumes.
- The addon list now shows the same bell icon as the minimap button.

## 1.1.0
- Sound settings are now bi-directional. Changing a volume or mute in the game's own
  audio options saves it into the profile currently in force, the same one the addon
  window edits, so both stay in sync.

## 1.0.1
- Fixed toc version

## 1.0.0
- Initial release
